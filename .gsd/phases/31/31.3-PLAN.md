# Plan 31.3: Conversational Menus, Drip Integrity & Visit Confirmation

## Objective
1. Fix Menu Option "1" Recognition:
   - When user replies "1" at initial menu (`1: Property Buy ya Rent karni hai`), do NOT apologize or act confused. Seamlessly start Seeker qualification.
   - When a returning lead with active search options sends "1" (`Top property options dekhne hain`), display the top matching property options instead of asking Purpose.
2. Follow-Up Drip & Briefing Integrity:
   - In `runFollowupEngine` / `runMorningBriefingEngine` / `runOptionsNudge`:
     - If the lead never received direct property options (`NO_PROPERTY_MATCH` or empty `last_option_ids`), DO NOT send "Jo properties humne share ki thin (jaise Griham Green Valley Enclave)...".
     - Instead send a dedicated off-market concierge follow-up: "Hamare advisors off-market options arrange kar rahe hain...".
     - Never recommend a residential plot (Griham Green Valley Enclave) to a commercial shop/office seeker! Match property category strictly.
3. Compound Inquiry & Visit Confirmation:
   - In compound messages like `Alkapuri area me 3bhk flat buy krna he 1 cr ke budget me`, ensure all extracted fields (`location`, `property_type`, `requirement`, `budget`) are recognized at once so the bot does NOT re-ask for location.
   - When a user has a visit scheduled today and receives morning briefing asking "Kya hum timing confirm samjhein?", if user replies "Ha" / "Yes" / "Sure", acknowledge the visit confirmation. Do NOT treat it as a new visit booking and re-ask time slots.
