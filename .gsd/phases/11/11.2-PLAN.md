# Plan 11.2: Apple HIG Compact Activity Stream Component & Segmented Actor Filter (UI Layer)

<objective>
Redesign `HistoryTimeline` into a world-class, Apple-grade, high-density operational workstation component. Eliminate bloated, repetitive 100px cards that flood the screen with raw chat transcripts. Provide a 3-way segmented filter ("All", "👤 Sales Rep", "🤖 AI Bot"), a top KPI summary strip (e.g. Calls, Notes, AI Automations), compact date-grouped timeline rows (36px-44px), and progressive disclosure (click to expand full note/diff details).

Purpose: Allow sales executives and managers to instantly understand who did what (human vs bot) at a glance without getting lost in endless scrolling.
Output: Redesigned `src/components/crm/history-timeline.tsx` and updated `src/components/crm/lead-drawer.tsx`.
</objective>

  <name>Redesign HistoryTimeline with Apple Segmented Control, Compact Rows & Progressive Disclosure</name>
  <files>src/components/crm/history-timeline.tsx</files>
  <action>
    1. Implement 3-way Segmented Actor Filter at the top:
       - **All (`totalCount`)**
       - **👤 Sales Rep (`salesRepCount`)** — filtered to human actions (calls, notes, manual status changes, assignments, takeover)
       - **🤖 AI Bot (`aiBotCount`)** — filtered to bot actions (inbound qualification, property options shared, site visit booking, automated follow-up drips)
    2. Add a compact summary metric ribbon:
       - Mini pill badges showing: `📞 X Calls`, `📝 Y Notes`, `🤖 Z Automations`, `⚡ Last: 12m ago`.
    3. Build Ultra-Compact Timeline Row Structure:
       - Row height: ~40px (compact, data-dense, hairline border, squircle hover).
       - Left: Actor micro-badge / icon:
         - Sales Rep: Indigo / Blue avatar dot or `PhoneCall` / `UserCheck` / `FileText` icon.
         - AI Bot: Emerald / Teal spark node (`Sparkles` / `Bot`).
       - Center:
         - Bold, concise action title (e.g. "Logged Call: Interested in 3BHK", "AI Shared 3 Options in Alkapuri", "Status Changed to SITE_VISIT_BOOKED").
         - Subtle secondary subtitle: actor name (`Amit Patel` vs `AI Lead Engine`) + diff pill if a field changed (`Status: NEW → BOOKED`).
       - Right: Compact relative timestamp (`12m ago`, `2h ago`, `Yesterday 5:00 PM`) in `tabular-nums font-mono text-[11px]`.
    4. Implement Progressive Disclosure (Expandable Accordion):
       - If an activity has an extended note, field diff, or message preview, clicking the row smoothly expands a compact frosted inset showing the full note/details.
       - Include a subtle chevron or expand indicator so the user knows details are accessible without bloating the list.
    5. Date Grouping:
       - Render items grouped by "Today", "Yesterday", "This Week", and "Older" with subtle hairline divider headers.
    6. Empty State:
       - Clean, friendly Apple empty state if the selected actor filter has no items (e.g. "No sales executive actions logged yet - log a call or note below!").
    AVOID: Dumping raw multi-line HTML bot messages.
    AVOID: Bulky 100px cards that take up half the viewport.
    AVOID: External animation or chart libraries (0 extra runtime JS packages).
  </action>
  <verify>Run `npm.cmd run build` to confirm zero TypeScript and CSS regressions.</verify>
  <done>HistoryTimeline provides instant actor segmentation, compact 40px rows, date grouping, and expandable note details.</done>
