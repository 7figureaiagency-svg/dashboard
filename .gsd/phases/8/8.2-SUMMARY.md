## Changes Made
1. **Removed Direct Access Demo Mode (`src/routes/auth.tsx`):**
   - Completely deleted the "🚀 Direct Access Dashboard (Nextgen Realty)" button and its `localStorage.setItem("demo_mode", "true")` handler.
   - Authentication is now strictly enforced through email & password via `supabase.auth.signInWithPassword`.

2. **Strict Route Guard Protection (`src/routes/_authenticated/route.tsx`):**
   - Eliminated the `isDemo` check and mock admin user fallback (`demo-admin-id`).
   - Every request to protected routes verifies an active Supabase session with `await supabase.auth.getUser()`, redirecting unauthenticated visitors to `/auth`.

3. **Dynamic User & Tenant Scope Resolution (`src/lib/auth.ts`):**
   - Removed `isDemo` mock admin branch and hardcoded Nextgen Realty fallback (`8699dca1-2b97-4367-85b8-8a0db2fd51f5`).
   - `useCurrentUser` now dynamically queries `public.profiles` for `id = user.id`, extracting `client_id`, `role`, and `full_name`.

4. **Multi-Tenant Dashboard Branding (`src/lib/crm-data.ts`, `src/routes/_authenticated/dashboard.tsx`):**
   - `useClient` now enables query only when `clientId` is present (`enabled: !!clientId`) and falls back to `"Real Estate CRM"` instead of hardcoding Nextgen Realty.
   - `approvePropertySubmission` strictly validates `client_id` without defaulting to Nextgen Realty.
   - Dashboard header title renders `{client?.company_name || client?.name || "Real Estate CRM"}`.
