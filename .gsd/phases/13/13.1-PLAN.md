# Plan 13.1: Database Schema Expansion & Edge Function Dynamic AI Knowledge Engine

## Objective
Enable client-specific dynamic FAQ and identity responses in the AI bot without regex by adding a structured `bot_knowledge` JSONB column to `public.clients`, seeding default profiles for Griham Realty and NextGen Realty, and upgrading `realtor-lead-engine` to inject client-specific knowledge (office address, operating hours, brokerage policy, bank partners, and custom Q&As) into the conversational AI response generator.

## Invariants
1. **100% Non-n8n Architecture:** All logic stays in Supabase Edge Functions + PostgreSQL + React frontend.
2. **Strict Multi-Tenant Isolation:** `bot_knowledge` is strictly scoped to `activeTenantId` (`client_id`).
3. **No Regex for Intent Understanding:** Intent classification uses Gemini/Groq Micro-LLM; factual answers strictly cite database knowledge to prevent AI hallucinations.
4. **0 Extra JS Packages:** Pure TypeScript.
