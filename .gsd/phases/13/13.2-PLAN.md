# Plan 13.2: Apple HIG Profile Tab "AI Bot Knowledge & FAQ Studio" UI

## Objective
Design and implement an Apple HIG-grade "AI Bot Knowledge & FAQ Studio" card in the CRM Profile Tab (`src/components/crm/profile-tab.tsx`), enabling Organization Admins to configure their agency's office address, visiting hours, brokerage policies, banking partners, and custom Q&A items, with 1-click optimistic saving to `public.clients.bot_knowledge` and an interactive live bot response preview.

## Invariants
1. **0 Extra JS Packages:** Pure Tailwind CSS v4, Lucide React icons, and existing UI components.
2. **Apple HIG Design Language:** Translucent materials (`.apple-card`), squircle border radiuses (`rounded-2xl`), hairline borders, and clear hierarchy.
3. **Strict Multi-Tenant Scoping:** Admin can only view and mutate their own tenant's `bot_knowledge`.
