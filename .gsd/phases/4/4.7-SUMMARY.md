# Plan 4.7 Execution Summary: Past Site Visit Temporal Greeting Guards & Missed Visit Cron Sweep

## Overview
Resolved the issue reported for Telegram lead Manthan (`5117510624`):
1. **Past Site Visit Greeting Fix**: When a lead texted "Hi" hours after their 10:00 AM visit had elapsed, the bot was labeling it as "Upcoming Site Visit" because `hasActiveVisit` checked boolean truthiness of `lead.site_visit_at` (a persistent DB timestamp string) rather than verifying whether `scheduled_at > Date.now()`.
2. **Missing Post-Visit / Missed-Visit Follow-Up**: Leads who missed their visit were previously skipped by the cron sweeps because Module 2 queried `site_visit_booked = true` and Module 2B excluded `VISIT_MISSED`. Added Module 2C to automatically dispatch courteous rescheduling invitations within business hours.

## Key Changes Implemented

1. **Temporal Classification in `dispatchStateAction`**:
   - Location: `supabase/functions/realtor-lead-engine/index.ts` lines 3953–4045.
   - Evaluates:
     - `isUpcomingVisit = activeVisit && site_visit_booked && scheduled_at > now`
     - `isPastUnconfirmed = activeVisit && status in ['SCHEDULED','CONFIRMED','RESCHEDULED'] && scheduled_at <= now`
     - `isMissedVisit = state === 'VISIT_MISSED' || status === 'MISSED'`
   - Template Output:
     - Upcoming: `"🚗 Upcoming Site Visit: ..."` $\to$ Option 1: `"Site Visit Details / Property Search"`
     - Past Unconfirmed: `"🚗 Site Visit Update: ... no samay viti gayo chhe. Shu attend kari shakya hata?"` $\to$ Option 1: `"Visit Attendance / Reschedule"`
     - Missed: `"🚗 Site Visit: ... miss ho gayi thi. Kya naya slot reschedule karna hai?"` $\to$ Option 1: `"Visit Reschedule / Nayi Property Search"`
     - Clean search: `"🏡 Active Property Search: ..."` $\to$ Option 1: `"Property Search Options"`

2. **Temporal Guard in `DUAL_ROLE_MENU_PENDING` Option 1 Handling**:
   - Location: `supabase/functions/realtor-lead-engine/index.ts` lines 4400–4475.
   - For missed visits, prompts with `kal shaam 4:00 baje ya 5:30 baje` rescheduling slots and 'Search' fallback instead of falsely asserting that a past visit is confirmed.

3. **Temporal Guard in `SITE_VISIT_BOOKED` Greeting**:
   - Location: `supabase/functions/realtor-lead-engine/index.ts` lines 4945–4975.
   - Checks `isFuture`. If visit time has passed, prompts for attendance confirmation / reschedule instead of saying "Milte hain site par!".

4. **Module 2C in Automated Cron Sweep**:
   - Location: `supabase/functions/realtor-lead-engine/index.ts` lines 2800–2890.
   - Targets `VISIT_MISSED` leads who missed a visit $>2$ hours ago.
   - Sends polite rescheduling invitation within business hours (11:00 AM – 6:30 PM IST).
   - Updates `metadata.missed_visit_reschedule_nudge_sent = true` and logs `lead_events`.
