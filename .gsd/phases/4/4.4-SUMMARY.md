## 1. Accomplishments & Bug Resolutions

### BUG-01 (P1 - High): Onboarding Webhook Fallback
- **Problem**: `src/lib/onboarding.functions.ts` used `"https://n8n.yourdomain.com/webhook/meta-whatsapp"` as the default fallback when `META_WEBHOOK_URL` was unset, routing incoming WhatsApp leads to an unconfigured n8n host.
- **Fix**: Updated `META_WEBHOOK_URL` in `src/lib/onboarding.functions.ts` to route directly to live Supabase Edge Function:  
  `https://yeiygfysijptjdepctnx.supabase.co/functions/v1/realtor-lead-engine/webhook`.

### BUG-02 (P2 - Medium): 10-Digit Indian Phone Number Normalization
- **Problem**: Raw 10-digit Indian numbers (`9820144821`) in `wa.me/` URLs caused WhatsApp to mistake `98` for the Iran international country code (+98), failing to open Indian client conversations.
- **Fix**: Implemented and exported central `toWhatsAppUrl(phone, text)` in `src/lib/crm.ts`. Automatically prepends `91` when `digits.length === 10` or strips leading `0` when `digits.length === 11`.
- **Adoption**: Replaced all direct `wa.me/` string concatenations in `leads-tab.tsx` and `lead-drawer.tsx` with `toWhatsAppUrl`.

### BUG-03 (P2 - Medium): Desktop Pipeline Table 1-Tap WhatsApp CTA
- **Problem**: Desktop table rows only displayed `Call` and `Open`, forcing sales executives to open the drawer to initiate WhatsApp contact.
- **Fix**: Added high-visibility 1-tap WhatsApp button with `Send` icon and emerald luxury styling directly inside each desktop table row's Actions cluster in `src/components/crm/leads-tab.tsx`.

### BUG-04 (P3 - Low): Outdated Compliance Copy
- **Problem**: Legal pages (`privacy-policy.tsx` and `terms.tsx`) still listed n8n as our automation provider.
- **Fix**: Replaced references to n8n with Supabase Edge Functions and updated third-party downtime disclaimer to `(Meta, Supabase, Vercel)`.
