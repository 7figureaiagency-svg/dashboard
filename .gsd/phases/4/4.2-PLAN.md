# Plan 4.2: CRM Dashboard Dual-Role Badges, Drawer Sub-Tabs & High-Value Sales Alerts

## Objective
Extend the Nextgen Realtors Apple HIG CRM Dashboard with full visual transparency for multi-persona clients. Provide distinct `[🌟 DUAL: BUYER + SELLER]` badges in lead lists and pipeline stages, a dedicated "Seller Submissions" view inside the Lead Detail Drawer alongside the Buyer Profile, and actionable sales alert hints for combined buying and selling transactions.

## Context
- Plan 4.1 establishes backend dual-role persistence (`lead_type: 'DUAL_ROLE'`, parallel `property_submissions` rows, and `DUAL_ROLE_MENU_PENDING`).
- `src/lib/crm-data.ts` already provides `usePropertySubmissions()` hook.
- Strict Non-n8n rule: all UI state is driven by Supabase queries and React TanStack hooks.
- Mobile Ergonomics: 44pt touch targets, Apple Inset-Grouped cards.
