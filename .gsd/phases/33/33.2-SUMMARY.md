## 3. Architecture & Implementation Details

### 3.1 Real Estate Extraction JSON Schema (`REAL_ESTATE_EXTRACTION_SCHEMA`)
Structured according to Google Gemini `generationConfig.responseSchema`:
- `lead_role`: enum `["BUYER", "TENANT", "SELLER", "LANDLORD", "BROKER", "UNKNOWN"]`
- `primary_intent`: enum `["NEW_INQUIRY", "SELECT_OPTION", "CONFIRM_VISIT", "RESCHEDULE_VISIT", "CANCEL_VISIT", "CHANGE_CRITERIA", "SIDE_FAQ", "GREETING_ONLY", "NEGATION_CORRECTION", "HUMAN_ESCALATION"]`
- `direct_answer_to_last_question`: boolean
- `user_negated_assumptions`: boolean
- `negation_explanation`: string | null
- `selected_menu_option`: integer (1, 2, 3, 4) | null (strictly 1-based human menu choice)
- `entities`:
  - `property_category`: enum `["RESIDENTIAL", "COMMERCIAL", "PLOT_LAND", "UNKNOWN"]`
  - `property_type`: enum `["FLAT", "TENEMENT", "DUPLEX", "VILLA", "SHOP", "OFFICE", "PLOT", "UNKNOWN"]`
  - `unit_bhk`: integer (1, 2, 3, 4, 5) | null
  - `budget_inr`: integer (normalized in Rupees: 50L -> 5000000, 1 Cr -> 10000000) | null
  - `budget_type`: enum `["OUTRIGHT_BUY", "MONTHLY_RENT", "COMMERCIAL_LEASE", "UNKNOWN"]`
  - `location_name`: string | null (clean locality, strictly excluding property subtypes or adjectives)
  - `purpose`: enum `["END_USE", "INVESTMENT", "UNKNOWN"]`
  - `timeline`: enum `["READY_TO_MOVE", "UNDER_CONSTRUCTION", "UNKNOWN"]`
  - `carpet_area_sqft`: integer | null
  - `floor`: integer | null
  - `furnishing`: enum `["UNFURNISHED", "SEMI_FURNISHED", "FULLY_FURNISHED", "UNKNOWN"]`
- `user_side_question`: string | null
- `detected_language`: object with `code`, `dialect`, `script`

### 3.2 Context-Conditioned Prompting (`buildCognitivePrompt`)
Injects:
- Active Lead State & Persona (`lead.state`, `lead.lead_type`)
- Pending Bot Question Type (`last_bot_prompt.question_type`, `text_preview`)
- Last 6 conversation turns
- Explicit disambiguation rules preventing property type leakage into society/project names, handling seller vs seeker negations, and normalizing numeric currency.

### 3.3 Auto-Escalation & Fallback Strategy

```
+-------------------------------------------------------------+
                              |

             Gemini 2.5 Flash (responseSchema)

        +---------------------+---------------------+

        |                                           |

  Gemini 2.5 Pro Auto-Escalation                    |
        |                                           |
        +---------------------+---------------------+
                              |
                     (If Gemini Fails)
                              v
               Groq Llama-3.3-70b (json_object)
                              |
                     (If Groq Fails)
                              v
            Resilient Deterministic Cognitive Engine
```

### 3.4 FSM Bridge Mapping (`mapCognitiveResultToActionResult`)
- Converts typed extraction output into `ClassifiedActionResult` conforming to FSM requirements:
  - Maps `lead_role` ("SELLER" / "LANDLORD") -> `user_role: "OWNER"`
  - Maps `lead_role` ("BUYER" / "TENANT") -> `user_role: "SEEKER"`
  - Disambiguates `selected_menu_option` in state-conditioned contexts (`SITE_VISIT_DONE`, `ROLE_SELECTION_PENDING`, `OPTIONS_SENT`)
  - Formats property type strings (e.g. `1BHK Tenement`, `2BHK Flat`)
  - Populates backward-compatible bridge fields (`property_type`, `location`, `price_or_budget`, `transaction_type`, `carpet_sqft`)
