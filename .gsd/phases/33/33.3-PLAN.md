# Plan 33.3: Universal Multilingual Dynamic Synthesizer

<objective>
Replace rigid static reply strings with a universal multilingual dynamic response generator powered by Gemini 2.5 Flash, capable of naturally conversing in all 22 scheduled Indian languages and vernacular regional dialects (Hindi, Gujarati, Marathi, Tamil, Telugu, Kannada, Bengali, Punjabi, Marwari, Kathiyawadi, Hinglish, Gujlish, English) while strictly maintaining real estate domain precision and respectful cultural etiquette.
</objective>

<context>
- Previously, hardcoded template strings caused awkward dialect mismatches (e.g. speaking generic Hindi to a Gujarati-speaking or Marathi-speaking lead).
- Real estate inquiries demand both linguistic authenticity (warm, respectful, local tone) and domain rigor (correct ₹ Lakh/Crore formatting, BHK configurations, carpet area, site visit times).
- By persisting `language_profile` in `leads.metadata`, the agent can permanently lock into the lead's preferred language and dialect across all future turns.
</context>

       - Inputs:

         > Language & Dialect: Strictly write in {dialect} using {script}.
         > Real Estate Rules: Never hallucinate prices or inventory. Use standard Indian real estate conventions (BHK, Lakh, Crore, Carpet Area). Be polite, respectful, and direct."

    3. Add fallback to curated regional templates if LLM synthesis experiences unexpected delay or failure.
