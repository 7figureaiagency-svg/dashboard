# Plan 33.1: Multimodal Voice Note Ingestion Engine

<objective>
Enable seamless ingestion and high-accuracy transcription of voice notes received via Telegram (`msg.voice` / `msg.audio`) and WhatsApp Cloud API (`messages[0].type === "audio"`), utilizing Groq Whisper-large-v3 as the ultra-fast primary transcriber (~180ms) with Gemini 2.5 Flash Audio API as zero-downtime fallback, so spoken real estate inquiries are handled with zero friction.
</objective>

<context>
- Currently, line 11608 of `supabase/functions/realtor-lead-engine/index.ts` drops incoming voice messages: `if (!messageText) return new Response(JSON.stringify({ status: "ignored", reason: "empty message" }))`.
- Telegram provides `voice` object with `file_id`. Calling `https://api.telegram.org/bot<token>/getFile?file_id=<file_id>` returns `file_path`, allowing audio buffer download from `https://api.telegram.org/file/bot<token>/<file_path>`.
- WhatsApp Cloud API provides `messages[0].audio.id`. Calling `https://graph.facebook.com/v20.0/<audio_id>` returns a download URL, which can be fetched with the WhatsApp Bearer token.
- Groq API (`GROQ_API_KEY` already present in environment) provides Whisper-large-v3 with superhuman transcription across Indian accents (Hindi, Gujarati, Marathi, Tamil, etc.) and code-switching (Hinglish, Gujlish).
- Gemini API (`GEMINI_API_KEY` already present in environment) supports direct audio bytes multimodal processing as a fallback.
</context>
