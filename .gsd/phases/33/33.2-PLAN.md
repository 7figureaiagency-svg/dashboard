# Plan 33.2: Zero-Regex Cognitive Intent & Entity Extractor

<objective>
Replace all brittle regex cascades, string searching, and keyword heuristics with a strongly-typed Gemini 2.5 Flash / Pro Structured JSON Schema (`responseSchema`) cognitive extractor that analyzes the user's message in the context of recent chat turns, correctly recognizing seller intent, buyer criteria, property configurations, numeric options, and negations with 100% precision.
</objective>

<context>
- Previously, regex heuristics caused numerous regressions:
  - "1bhk ternament" -> extracted "ternament" as society name.
  - "shop bechni he lena nahi" -> confused with commercial lease seeker because of keyword "shop".
  - Numeric option "2" -> collided with option index 2 (Option 3: search new property).
  - Adjectives like "juno", "purana" were misidentified as locations or projects.
- Gemini 2.5 Flash supports `responseSchema` with strict JSON Schema constraints, guaranteeing typed output.
- Groq Llama-3.3-70b supports structured JSON mode as a high-speed fallback.
</context>
