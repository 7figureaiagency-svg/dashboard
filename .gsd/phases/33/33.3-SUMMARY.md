## 3. Architecture & Implementation Details

### 3.1 Persistent Language Profile (`LanguageProfile`)
Maintained under `leads.metadata.language_profile`:
```json
{
  "primary_language": "Gujarati",
  "language_code": "gu-IN",
  "dialect": "Gujlish",
  "script": "Latin",
  "formality": "POLITE_RESPECTFUL",
  "detected_at": "2026-10-29T17:34:00.000Z"
}
```

### 3.2 Dynamic Language Switching & Continuity
- **Continuity Guard:** Isolated numeric choices ("1", "2", "3", "4", "5") and short tokens/greetings ("hi", "hello", "ok", "done", "yes", "ha") never disrupt or flip an established `language_profile`.
- **Dynamic Handoff:** Complete sentences or explicit requests ("Can you please share details in English?", "मला 3bhk फ्लॅट पाहिजे") immediately update `language_profile` and synchronize `leads.user_language`.

### 3.3 Dynamic Synthesizer Pipeline (`synthesizeMultilingualReply`)
1. **Tier 1 (Sub-350ms Primary):** Google Gemini 2.5 Flash with structured prompt conditioning on recipient name, role, goal, property summary, available visit slots, brochure links, and strict WhatsApp formatting (<= 4 lines).
2. **Tier 2 (Fallback):** Groq `llama-3.3-70b-versatile` executing with system instruction preserving local dialects.
3. **Tier 3 (Offline / Error Fallback):** `getCuratedRegionalFallback` providing culturally tailored responses in pure Gujarati script, Gujlish, Devanagari Hindi, Hinglish, Marathi, Tamil, Telugu, and English.
