# Plan 21.1: Core Pitch Engineering Library, Copywriting Frameworks & Skill Specification

<objective>
Build the domain intelligence and algorithmic foundation of the `property-pitch-crafter` system:
1. Define the `.agents/skills/property-pitch-crafter/SKILL.md` skill and reference documentation specifying 4 psychological buyer archetypes (`FAMILY_END_USER`, `INVESTOR_ROI`, `LUXURY_HNW`, `BUDGET_FIRST_TIME`), 3 regional linguistic dialects (`HINGLISH`, `GUJLISH`, `ENGLISH`), and 3 high-converting messaging formats.
2. Implement `src/lib/pitch-crafter.ts`: a zero-dependency TypeScript engine that extracts property/lead specs, calculates approximate home loan EMIs and price metrics, auto-selects appropriate buyer personas, and formats WhatsApp-ready copy with emojis and verified `wa.me` links.
3. Validate empirically with `scratch/test_pitch_crafter.cjs` to confirm 100% coverage across all 36 pitch permutations without runtime errors.
</objective>

<context>
- Currently, CRM pitch text in `inventory-tab.tsx` and `lead-drawer.tsx` is basic and hardcoded (e.g. generic greeting + budget).
- Indian real estate buyers have distinct triggers:
  - Families care about carpet area, schools, Vastu, and quiet surroundings.
  - Investors care about rental yields, upcoming infrastructure corridors, and capital appreciation velocity.
  - High-Net-Worth individuals care about privacy, low-density exclusivity, and premium lifestyle amenities.
  - First-time buyers care about down payments, monthly EMI calculations, and festive price advantages.
- Invariants:
  - 100% Non-n8n (pure client/edge logic)
  - 0 additional runtime JS packages (pure TypeScript mathematical formulas and template interpolation)
  - Strict multi-tenant safety
</context>

    1. Create `src/lib/pitch-crafter.ts`:
       - Define strict TypeScript types:
         `type PitchPersona = "FAMILY_END_USER" | "INVESTOR_ROI" | "LUXURY_HNW" | "BUDGET_FIRST_TIME";`
         `type PitchLanguage = "HINGLISH" | "GUJLISH" | "ENGLISH";`
         `type PitchFormat = "WHATSAPP_QUICK" | "PORTFOLIO_DEEP_DIVE" | "URGENT_SCARCITY";`
         `interface PitchOptions { persona?: PitchPersona; language?: PitchLanguage; format?: PitchFormat; customNote?: string; }`
         `interface PitchResult { headline: string; body: string; cta: string; fullMessage: string; waUrl: string | null; estimatedEmi: string | null; persona: PitchPersona; language: PitchLanguage; format: PitchFormat; }`
       - Implement financial helper functions:
         - `calculateApproxMonthlyEmi(principal: number, annualRatePct = 8.5, tenureYears = 20): number`
         - `calculatePricePerSqFt(price: number, sqft: number): number | null`
       - Implement `inferBestPersona(lead?: Lead | null, propertyPrice?: number): PitchPersona`:
         - If lead budget/property price >= 1.25 Cr -> `LUXURY_HNW`
         - If lead requirement mentions "invest", "roi", "commercial", "rental", "shop", "plot" -> `INVESTOR_ROI`
         - If lead budget/property price <= 45 Lakhs -> `BUDGET_FIRST_TIME`
         - Default -> `FAMILY_END_USER`
       - Implement `craftPropertyPitch(property: Property | PropertySubmission, lead?: Lead | null, options?: PitchOptions): PitchResult`:
         - Normalizes property attributes (society/project name, configuration, locality, price/rent, carpet area, furnishing, possession).
         - Resolves client name, executive contact, and target phone.
         - Interpolates tailored copy based on the 4 personas, 3 languages, and 3 formats.
         - Encodes `waUrl` via `toWhatsAppUrl`.

       - Tests all 4 personas across Hinglish, Gujlish, and English.
       - Tests EMI calculation accuracy on ₹50L, ₹85L, and ₹1.5 Cr properties.
       - Asserts all output strings are non-empty, contain expected pricing/locality tokens, and produce valid WhatsApp URLs.
       - Run with `node scratch/test_pitch_crafter.cjs`.
    AVOID: Any external dependencies or libraries. Keep it 100% pure TypeScript / JavaScript.
