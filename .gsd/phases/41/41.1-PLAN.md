# Plan 41.1: Mid-Flow Role-Switch Circuit Breaker & `handleOwnerFlow` AI Modernization

## Objective
Eradicate hardcoded decision regexes in `handleOwnerFlow` (`isSecondListing`, `isSeekerInquiry`, `isDecliningSecondListing`, `isStatusInquiry`) and implement a top-level Mid-Flow Role-Switch Circuit Breaker in `processIncomingMessage`. Ensure that when a lead in any `OWNER_*` state (or `OWNER_DETAILS_GATHERED`) sends a message indicating buyer intent (e.g. `"muje flat lena he"`, `"mare harni area ma 3bhk flat buy krvo che"`), the bot immediately switches persona to `BUYER`, archives the owner draft, and enters `handleQualificationCascade` without hallucination or trapped state loops.

## Context
- File: `supabase/functions/realtor-lead-engine/index.ts`
- Root Cause:
  1. `handleOwnerFlow` line 6962 regex `/^(?:2|ha|haan|yes|dusri).*/` greedily matched `"ha muje dusra flat lena he"` and started a 2nd seller listing.
  2. `isSeekerInquiry` line 6977 checked only `chahiye|joiye|buy|kharid` and missed natural vernacular like `lena`, `levo`, `dekhna`.
  3. `isInOwnerIntake` trapped incoming turns inside `handleOwnerFlow` even when `cognitiveTurn.active_role === "BUYER"`.

## Tasks

### Task 1: Top-Level Mid-Flow Role-Switch Circuit Breaker
- In `processIncomingMessage`:
  Before delegating to `handleOwnerFlow` for `isInOwnerIntake` or `currentState === "OWNER_DETAILS_GATHERED"`:
  Check if AI perception indicates buyer inquiry:
  ```typescript
  const isSwitchingToBuyer = Boolean(
    cognitiveTurn?.active_role === "BUYER" ||
    cognitiveTurn?.primary_intent === "SEARCH_PROPERTY" ||
    (actionResult.requirement === "BUY" && actionResult.property_type)
  );
  ```
  If `isSwitchingToBuyer`:
  1. Check if an active owner draft exists and archive it safely to `archived_submissions` (or ensure existing completed submission is intact).
  2. Update lead: `lead.lead_type = "DUAL_ROLE"`, `lead.state = "QUALIFYING"`, `metadata.active_persona = "BUYER"`, `metadata.has_buyer_profile = true`.
  3. Seamlessly delegate to `handleQualificationCascade(lead, actionResult, context)` so buyer slots are processed immediately in the very same turn!

### Task 2: AI-Driven Intent Modernization inside `handleOwnerFlow`
- In `handleOwnerFlow`:
  1. Replace `isSecondListing`:
     Only consider second listing if `(cognitiveTurn?.primary_intent === "SUBMIT_PROPERTY" || actionResult.action?.intent === "SUBMIT_LISTING") && cognitiveTurn?.active_role !== "BUYER"`.
     If `cognitiveTurn?.active_role === "BUYER"`, NEVER trigger `isSecondListing`.
  2. Replace `isSeekerInquiry`:
     Trigger buyer switch if `cognitiveTurn?.active_role === "BUYER" || cognitiveTurn?.primary_intent === "SEARCH_PROPERTY" || actionResult.requirement === "BUY"`.
  3. Replace `isDecliningSecondListing`:
     Check if user is explicitly declining or opting out (`cognitiveTurn?.user_negated_assumptions || cognitiveTurn?.primary_intent === "OPT_OUT" || /^(?:nahi|no|na|nathi|rehne do)\b/i.test(lower.trim())`) while ensuring `cognitiveTurn?.active_role !== "BUYER"`.
  4. Replace `isStatusInquiry`:
     Check `cognitiveTurn?.primary_intent === "ASK_FAQ"` with status context.
