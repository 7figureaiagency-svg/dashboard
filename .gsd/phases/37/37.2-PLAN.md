# Plan 37.2: Option Selection Off-by-One Array Bounds Fix & Pan-India Multi-City Dynamic Resolution Engine

## Context & Objectives
1. **Option Selection Bug**:
   When bot sends property options (e.g. Option 1: Griham Heights, Option 2: Saraswati Bungalows), typing `"2"` fails with:
   *"Ji Manthan bhai, pasand kareli property ni details confirm nathi thai saki..."*.
   Root cause: Line 4594 sets `option_index = 2` (1-based from `extracted.selected_menu_option`), and Line 10960 does `lead.last_option_ids[idx]` which looks up index 2 on a 2-item array (bounds `0` and `1`), returning `undefined`.
2. **Pan-India Multi-City Resolution**:
   When user provides a City (e.g., "Vadodara", "Ahmedabad", "Surat", "Mumbai", "Pune", "Delhi", "Bangalore"):
   - Recognize it as a CITY, NOT a neighborhood/locality.
   - If it matches the operating market of the agency (or all-India): Acknowledge city warmly and explicitly prompt for the specific **Area / Locality** in that city.
   - Prevent any city name from accidentally defaulting to a hardcoded locality (e.g. "Alkapuri").
