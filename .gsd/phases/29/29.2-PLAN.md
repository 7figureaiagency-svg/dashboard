# Plan 29.2: Purpose-First Qualification Cascade & Investment Zero-Location Fast-Path

<objective>
Re-engineer the buyer qualification state machine in `handleQualificationCascade` to align with elite PropTech domain logic:
1. Prioritize Purpose (Self-Use vs Investment) BEFORE Locality. In real estate, investors prioritize ROI, yield, and asset quality over a single street—asking an investor for a specific neighborhood creates friction. If purpose is Investment, the location question is bypassed entirely with `location = "FLEXIBLE"`.
2. Decouple compound questions into adaptive single-turn prompts so that answering one question does not re-trigger compound questions.
3. Guarantee that Timeline (Ready to Move vs Under Construction) is never lost or skipped.
4. Present live matching inventory with high-conversion hyperlinked cards and a 1-tap VIP Site Visit CTA.

Purpose: Live testing by user (Telegram ID 5117510624) demonstrated that asking Location before Purpose is frustrating for investors and causes Timeline to be repeatedly skipped.
Output: Redesigned buyer qualification cascade in `supabase/functions/realtor-lead-engine/index.ts`.
</objective>

  <name>Task 1: Purpose-First Qualification Architecture & Investment Fast-Path</name>
  <files>supabase/functions/realtor-lead-engine/index.ts</files>
  <action>
    1. Reorder the qualification missing stage evaluation in `handleQualificationCascade`:
       - **Stage 1 (Configuration & Transaction):**
         - Ensure `property_type` (e.g. 2BHK, 3BHK Duplex, Villa, Shop) and `requirement` (`BUY`, `RENT`, `LEASE`) are captured.
         - If user answers only property type (e.g. "3bhk duplex"), acknowledge type and ask ONLY for Buy vs Rent:
           `Great choice! <b>3BHK Duplex</b>. 👍\n👉 Aap ye property <b>Buy (Kharidna)</b> chahte hain ya <b>Rent</b> par chahiye?`
         - If user answers only Buy/Rent, ask ONLY for Property Type.
       - **Stage 2 (Purpose / Intent):**
         - ASK PURPOSE BEFORE LOCATION!
         - Prompt:
           - Hinglish: `Samajh gaya! 👍\n👉 Yeh property aap <b>Family rehne (Self-Use)</b> ke liye dekh rahe hain ya <b>Investment</b> purpose se? 🔑`
           - Gujlish: `Samji gayo! 👍\n👉 Aa property tame <b>Family raheva (Self-Use)</b> mate joi rahya chho ke <b>Investment</b> purpose thi? 🔑`
           - English: `Understood! 👍\n👉 Are you looking for <b>Family living (Self-Use)</b> or for <b>Investment</b>? 🔑`
       - **Stage 3 (Location Routing based on Purpose):**
         - **If `purpose === "INVESTMENT"`:**
           - DO NOT ASK FOR LOCATION!
           - Automatically set `location = "FLEXIBLE"` and record `is_flexible_location = true`.
           - Acknowledge investment focus: `Sahi hai, investment ke liye pure city me best ROI aur appreciation wale options dekh lenge. 📈`
           - Advance immediately to Budget (Stage 4)!
         - **If `purpose === "SELF_USE"` (or not investment):**
           - If location is missing:
             - Hinglish: `Bahut badhiya! 👍\n👉 Aap kaunse preferred <b>Area ya Landmark</b> ke paas dekh rahe hain? 📍`
             - Gujlish: `Khub saras! 👍\n👉 Tame kaya preferred <b>Area ke Landmark</b> pase joi rahya chho? 📍`
             - English: `Great! 👍\n👉 Which preferred <b>Area or Landmark</b> are you looking around? 📍`
    AVOID: Asking for locality before understanding if the buyer is an investor.
  </action>
