**Executed Date:** 2026-10-27  
**Status:** Completed (Empirically Verified & Production Built)

## 1. Overview & Objectives

In Phase 24, Plan 24.2 addresses the frontend CRM vulnerabilities and ergonomics found during the QA audit:
1. **BUG-04 [P2] (Lead Drawer Executive Reassignment)**: Added an Apple HIG "Assigned Executive" selector in `LeadDrawer` profile form for Admins and Managers to directly reassign leads to executives.
2. **BUG-03 Invariant (Admin-Only Seller Governance)**: Strictly gated the Seller / Owner Submissions tab in `LeadDrawer` behind `isAdmin`, ensuring Sales Executives cannot see property submissions or listings.
3. **BUG-02 Policy (Zero Outbound Messages on Approval)**: Verified that `useApprovePropertySubmission` contains zero external messaging calls (`functions.invoke`, WhatsApp, Telegram) and added an internal-only audit log entry in `lead_events` with event type `PROPERTY_APPROVED_TO_INVENTORY`.
4. **BUG-05 [P3] (Activity Timeline Compound Sorting)**: Replaced single timestamp sorting with compound sort (`timestamp` descending + `id` localeCompare) across `useActivity` in `crm-data.ts` and `HistoryTimeline` to completely eliminate 1-2 second timestamp flicker.
5. **Dashboard Non-Admin Inventory Guard**: Enforced that non-admin authenticated users are prevented from opening the Inventory tab via state manipulation, automatically redirecting them to `leads`.

## 2. Key Changes Implemented

### A. Lead Drawer Executive Selector & Seller Tab Gate (`src/components/crm/lead-drawer.tsx`)
- Integrated `useCurrentUser` to derive `isAdmin` (`me?.role === "admin"`) and `canReassign` (`isAdmin || isManager`).
- Fetched tenant executives dynamically with `useExecutives(lead?.client_id)`.
- Added an Apple HIG `Select` dropdown for "Assigned Executive" in the Lead Profile form section, defaulted to `lead.assigned_executive_id` (or Unassigned) and rendered only for users with reassign privileges (`canReassign`).
- Wired `assigned_executive_id: selectedExecutiveId || null` in the `useUpdateLead` mutation payload upon clicking "Save Updates".
- Gated `<TabsTrigger value="seller">` and `<TabsContent value="seller">` behind `isAdmin && (submissions.length > 0 || isDual || field("lead_type") === "PROVIDER")`.

### B. Approval Mutation Audit Log & Zero Outbound Messaging (`src/lib/crm-data.ts`)
- Audited `useApprovePropertySubmission`: verified zero occurrences of `supabase.functions.invoke` or outbound messaging calls.
- Added internal audit log entry to `lead_events`:
  ```typescript
  if (submission.lead_id) {
    await supabase.from("lead_events").insert({
      lead_id: submission.lead_id,
      client_id: resolvedClientId,
      event_type: "PROPERTY_APPROVED_TO_INVENTORY",
      payload: {
        description: `Property listing approved and moved to live inventory. Inventory ID: ${propertyId}`,
        submission_id: submission.id,
        property_id: propertyId,
      },
      created_at: new Date().toISOString(),
    } as never);
  }
  ```

### C. Compound Sort for Activity Timeline (`src/lib/crm-data.ts` & `src/components/crm/history-timeline.tsx`)
- Updated `useActivity` query in `src/lib/crm-data.ts` to apply compound sort:
  ```typescript
  .sort((a, b) => {
    const timeDiff = new Date(b.created_at).getTime() - new Date(a.created_at).getTime();
    if (timeDiff !== 0) return timeDiff;
    return String(b.id).localeCompare(String(a.id));
  });
  ```
- Aligned `HistoryTimeline` in `src/components/crm/history-timeline.tsx` with identical secondary ID-based tiebreaker sort.

### D. Dashboard Non-Admin Inventory Guard (`src/routes/_authenticated/dashboard.tsx`)
- Confirmed `adminOnly: true` on the `inventory` nav item in `NAV_ITEMS`.
- Added active tab reset guard:
  ```typescript
  useEffect(() => {
    if (!isAdmin && activeTab === "inventory") {
      setActiveTab("leads");
    }
  }, [isAdmin, activeTab]);
  ```

### E. Test Suite (`scratch/test_phase24_bug_remediation.cjs`)

  1. DB RLS Migration exists with `current_executive_id()`, `is_admin()`, and policies.

  3. `useApprovePropertySubmission` zero outbound messages & `PROPERTY_APPROVED_TO_INVENTORY` audit log.
  4. Activity compound sort with `localeCompare`.
  5. Dashboard non-admin inventory guard with `adminOnly: true`.
