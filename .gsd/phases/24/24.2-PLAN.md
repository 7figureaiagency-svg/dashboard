# Plan 24.2: CRM Lead Drawer Executive Reassignment, Admin Seller Guard & Activity Timeline Polish

## Objective
Fix three CRM frontend bugs found in the Phase 24 QA Audit:
1. **BUG-04 [P2]**: Add an "Assigned Executive" selector to the LeadDrawer profile form so Admins/Managers can directly reassign a lead's `assigned_executive_id` without leaving the drawer.
2. **BUG-03 (Admin Invariant)**: Harden the "Seller" sub-tab in LeadDrawer — only Admins can view a lead's owner property submissions (Sales Executives must never see the Seller submissions tab).
3. **BUG-05 [P3]**: Stabilize the activity event timeline with compound sorting to eliminate 1-2 second timestamp flicker.
4. Ensure `useApprovePropertySubmission` in `crm-data.ts` includes an internal-only audit log event (`PROPERTY_APPROVED_TO_INVENTORY`) with **zero outbound WhatsApp/Telegram messages** (per user directive: "Outbound message hame kam se kam rakhne he").

Then validate with a targeted verification test suite and full `npm.cmd run build`.

       - Open `useApprovePropertySubmission` mutation in `src/lib/crm-data.ts`.
       - Verify the mutation does NOT call `supabase.functions.invoke(...)` or any external messaging endpoint.
       - After the `inventory` insert and `property_submissions` status update, add an internal CRM audit log entry:
         ```typescript
         await supabase.from("lead_events").insert({
           lead_id: submission.lead_id,
           client_id: resolvedClientId,
           event_type: "PROPERTY_APPROVED_TO_INVENTORY",
           description: `Property listing approved and moved to live inventory. Inventory ID: ${inventoryId}`,
           created_at: new Date().toISOString(),
         });
         ```
       - This is purely internal — zero outbound message to WhatsApp/Telegram.

    2. **Activity Timeline Compound Sorting** (BUG-05):
       - Find where activity events are sorted in `crm-data.ts` or relevant hooks (look for `.sort((a, b) => ...)`).
       - Replace single-field sort with compound sort:
         ```typescript
         .sort((a, b) => {
           const timeDiff = new Date(b.created_at).getTime() - new Date(a.created_at).getTime();
           if (timeDiff !== 0) return timeDiff;
           return b.id.localeCompare(a.id); // secondary sort by ID prevents flicker
         });
         ```

    3. **Dashboard Non-Admin Inventory Guard** (maintain admin invariant):
       - In `src/routes/_authenticated/dashboard.tsx`:
         - Ensure `adminOnly: true` remains on the `inventory` nav item.
         - Add a guard: if `!isAdmin && activeTab === 'inventory'`, reset `activeTab` to `'leads'`.
         - This prevents any URL manipulation or state leaks exposing the Inventory tab to non-admins.

    AVOID: Adding any supabase.functions.invoke or outbound messaging calls in the approval flow.
    USE: Internal `lead_events` table for audit logging only.
  </action>
