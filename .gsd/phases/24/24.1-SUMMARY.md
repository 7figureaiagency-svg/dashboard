# Phase 24 Plan 24.1: Database RLS Executive Hardening & Admin-Only Property Governance Summary

**Executed Date:** 2026-10-27  
**Status:** Completed (Empirically Verified in Production PostgreSQL)

---

## 1. Overview & Objectives

In Phase 24, Plan 24.1 addresses BUG-01 [P1] (executive lead data leak) identified during the E2E QA audit by enforcing strict database-level Row Level Security (RLS) rules:
1. Sales executives can only view and update their own assigned leads (or unassigned leads) within their tenant, eliminating the frontend filter bypass vulnerability.
2. The `property_submissions` table is strictly Admin-only (`is_admin() = true`) for SELECT, UPDATE, and DELETE operations, protecting sensitive owner resale records.
3. Edge Function and backend intake via `service_role` continue unhindered as `service_role` retains full bypass privileges.

---

## 2. Key Changes & Database Implementation

### A. Schema & Helper Functions
- Added `user_id uuid REFERENCES auth.users(id) ON DELETE SET NULL` column to `public.executives` with index `executives_user_id_idx`.
- Created `public.current_executive_id()` `SECURITY DEFINER` function resolving authenticated executive UUID from `auth.uid()`.
- Created `public.is_admin()` `SECURITY DEFINER` function returning boolean based on `public.profiles.role = 'admin'` for `auth.uid()::text`.

### B. Leads Table RLS Hardening
- Dropped legacy / bypass policies: `tenant_isolation_select`, `leads_tenant_select`, `leads_tenant_update`.
- Replaced `dashboard_select_leads` with:
  ```sql
  client_id = public.current_client_id() AND (
    public.is_admin()
    OR assigned_executive_id = public.current_executive_id()
    OR assigned_executive_id IS NULL
  )
  ```
- Replaced `dashboard_update_leads` with matching `USING` and `WITH CHECK` clauses.

### C. Property Submissions RLS Hardening
- Hardened `dashboard_select_property_submissions`, `dashboard_update_property_submissions`, and `dashboard_delete_property_submissions` to strictly require:
  ```sql
  client_id = public.current_client_id() AND public.is_admin()
  ```
- Retained `dashboard_insert_property_submissions` and `service_role_property_submissions`.

### D. Artifacts Created
- `supabase/migrations/20261027120000_executive_rls_and_admin_property_governance.sql`
