# Plan 34.1: Install & Tailor the `cs-chatbot-design` Domain Skill

<objective>
Install and customize the open-source `cs-chatbot-design` skill in `.agents/skills/cs-chatbot-design/SKILL.md` tailored specifically for Nextgn Realtors CRM and realtor-lead-engine, establishing foundational dialogue engineering rules (Intent Recognition, Structured Slot Filling, Response Principles: Acknowledge First, Be Concise, Offer Next Steps, and Fallback/Escalation Matrix), and register the skill in `AGENTS.md`.
</objective>

<context>
- Open-source agent skills (like `asgard-ai-platform/skills/cs-chatbot-design`) establish guidelines for building customer service chatbots, preventing two common anti-patterns:
  1. *Scripted bots:* Rigid decision trees that fail when users use unexpected phrasing.
  2. *Hallucinating bots:* Unstructured LLMs that invent policies, prices, or inventory.
- Nextgn Realtors CRM requires an enterprise PropTech adaptation of these principles, governing how our serverless edge submodules (`cognitive_extractor.ts`, `multilingual_synthesizer.ts`, `verifier_gate.ts`, and `index.ts`) converse with property seekers and owners.
</context>

       - `description`: Enterprise Conversational Chatbot Design System & Dialogue Engineering Governance for Nextgn Realtors CRM.
    2. Incorporate the core pillars:
       - **Intent Recognition & Zero-Regex Schema Governance** (TypeChat OpenAPI schema binding).
       - **Structured-Guided Slot Filling** (BHK, Budget, Locality, Timeline, Purpose, Floor, Furnishing).
       - **The 3 Golden Response Design Principles**:
         * *Rule 1: Acknowledge First* — Explicitly validate and echo the user's input before posing the next question.
         * *Rule 2: Be Concise* — Restrict replies to <= 3-4 lines with bullet points for WhatsApp/Telegram mobile readability.
         * *Rule 3: Offer Next Steps* — Provide 1-tap quick replies (`1️⃣`, `2️⃣`, `3️⃣`) to eliminate friction.
       - **Graceful Fallback & Human Escalation Protocol** (Empathetic clarify -> Contextual Recap -> Senior Executive Call Transfer).
