# Plan 34.2: Dialogue Governance Implementation & Production Deployment

<objective>
Apply the core principles of `cs-chatbot-design` directly into the `realtor-lead-engine` serverless submodules (`multilingual_synthesizer.ts`, `verifier_gate.ts`, and `index.ts`), enforcing the 3 Golden Response Principles (Acknowledge First, Be Concise, Offer Next Steps), validating compliance in the pre-flight reflection gate, verifying with an automated test suite, and deploying `v88-cs-chatbot-design-governance` to production.
</objective>

<context>
- With the `cs-chatbot-design` skill established in Plan 34.1, the engine's runtime dialog generators and validators must enforce these principles.
- Every bot turn must:
  1. Acknowledge what the user just provided.
  2. Answer or state the next objective concisely (under 4 lines for mobile readability).
  3. Offer clear next steps with 1-tap numbered options.
- The pre-flight verifier gate (`verifier_gate.ts`) will inspect proposed outbound replies against these rules before delivery.
</context>
