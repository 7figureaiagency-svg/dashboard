# Plan 22.1: State-Conditioned Multilingual Intent Engine (TypeChat + Active Question Context Injection)

<objective>
Upgrade the Realtor Lead Engine (`supabase/functions/realtor-lead-engine/index.ts`) with State-Conditioned Intent Classification incorporating all findings from the Code Review Audit (CR-P0 through CR-P3). By injecting the lead's active dialog state, pending question, and `last_bot_prompt` into the micro-LLM classifier prompt while enforcing an **Intent Precedence Hierarchy** and **Inverted Anti-OPT_OUT Guard**, eliminate context-blind classification failures where single-word and multi-word conversational answers (e.g. "Nahi", "Nahi karni", "2", "Bhade", "Option 1") get falsely flagged as OPT_OUT or OFF_TOPIC. Ensure 100% deterministic intent classification across all languages (Hindi, Gujlish, Gujarati script, English).

Purpose: In multi-turn chat, a user replying "Nahi karni" or "Nahi ja paaya" is answering the bot's specific question, not unsubscribing from service. Giving the LLM conversational state context makes intent recognition reliable across any regional language or slang, while preserving unprompted queries ("call me", "brochure bhej do").
Output: Hardened `index.ts` with state-conditioned prompting, centralized prompt tracking in `lead.metadata`, and an automated verification test suite.
</objective>
