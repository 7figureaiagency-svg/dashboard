# Plan 39.1: AI Single-Source of Truth for Intent & State Transitions

<objective>
Eliminate all business-decision regex cascades that override or bypass AI classification in the state machine, establishing the Gemini 2.0 Flash / Groq Llama 3.3 Cognitive Turn Router (`aiAnalysis`) as the unconditional single source of truth for all intent routing, menu selections, role determination, affirmations, and negations.
</objective>

<context>
- Currently, the state machine in `supabase/functions/realtor-lead-engine/index.ts` (lines 8000–12500) contains over 110 regex checks (such as `isGreetingInRole`, `isPureOption1`, `isPureOption2`, `isCancelYes`, `isChange`, `isOwnerIntentUtterance`, `PASSIVE_ACK_REGEX`) that run alongside or in priority over `aiAnalysis`.
- When users type complex, multi-lingual, or terse inputs (e.g., "1", "hi 3bhk chahiye", "kal 5 baje call karo", "rent nahi bechna hai"), these regexes trigger premature state transitions or hijack the AI's contextual understanding.
- In Phase 38, we fixed `parseBudgetFromText("1")`. In Phase 39.1, we generalize this across ALL states: state transitions must inspect `actionResult.intent`, `actionResult.selected_option_index`, `actionResult.user_role`, and `actionResult.extracted.primary_intent` instead of evaluating regex patterns on raw strings.
</context>
