# Plan 17.1 Summary: Portal-Exclusive Missing WhatsApp Banner & Telegram Lead Identity Isolation

## What Was Built
Fixed the issue where the amber warning banner *"Portal inquiry me WhatsApp number provide nahi kiya gaya"* and the bottom sticky CTA *"Add WhatsApp Number"* were incorrectly displaying on Telegram leads (such as Manthan `5117510624` in Griham Realty) and direct/manual leads.

### Key Changes
1. **Centralized Identity Predicates & Source Hydration (`src/lib/crm.ts`)**:
   - Implemented `isTelegramLead(lead)`: reliably detects Telegram leads via `lead.source`, `channel`, `platform === "TELEGRAM"`, `tg_`/`telegram_` prefix, or 7-14 digit numeric chat IDs where phone is absent or matches the chat ID.
   - Implemented `isPortalLead(lead)`: detects genuine real estate portal inquiries (`99acres`, `magicbricks`, `housing`, `commonfloor`, `olx`, `facebook`, `instagram`, `portal`, `portal_webhook`, or `portal_property_id`).
   - Updated `hydrateLead`: dynamically sets `source: "Telegram"` for Telegram leads rather than falling back to `"WhatsApp"`.

2. **Lead Drawer Inspector Refinement (`src/components/crm/lead-drawer.tsx`)**:
   - Guarded the amber warning banner strictly with `{isMissingPhone && isPortal && (...)}`.
   - Guarded `<NoWhatsAppBadge />` in the drawer header strictly with `{isMissingPhone && isPortal && <NoWhatsAppBadge />}`.
   - For Telegram leads: displays `Telegram ID: <id>` in the header subtitle without "No WhatsApp phone".
   - Sticky bottom action bar:
     - Telegram leads: renders frosted sky pill `Telegram ID: <id> · Direct calling unavailable`.
     - Portal leads with missing phone: renders amber `<Button>Add WhatsApp Number</Button>`.
     - Manual/Direct leads without phone: renders neutral outline `<Button>Add Phone Number</Button>`.
   - Add Phone modal: adjusts title and copy dynamically ("Add Verified WhatsApp Number" for portals vs "Add Phone Number" for manual leads).

3. **Leads CRM Table & Cards Refinement (`src/components/crm/leads-tab.tsx`)**:
   - Quick action filter `MISSING_PHONE` and counter `missingPhoneCount` now filter strictly by `isPortalLead(l) && isMissingPhone && !isTelegramLead(l)`.
   - Card view & desktop table:
     - If phone is present: displays phone number.
     - If Telegram lead: displays `TG: <lead_id>`.
     - If Portal lead with missing phone: displays `<NoWhatsAppBadge />` and "Add WhatsApp Number" button.
     - If Manual lead without phone: displays "No phone" and neutral "Add Phone" button.

## Verification
- `npm.cmd run build`: Compiled with 0 errors across all tasks.
- Manthan lead (`5117510624`) in Griham Realty:
  - Amber banner *"Portal inquiry me WhatsApp number provide nahi kiya gaya"* is gone.
  - Sticky bottom CTA shows `Telegram ID: 5117510624 · Direct calling unavailable`.
  - Desktop table and mobile card show `TG: 5117510624`.
- Genuine portal leads continue to display the amber banner and "Add WhatsApp Number" CTA as designed.
