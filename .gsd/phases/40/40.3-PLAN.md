<context>
- Following Plans 40.1 and 40.2, the perception and slot memory layers are solid.
- Now we need the Action/Presentation layer to present clean WhatsApp/Telegram cards, handle site visit booking with natural example formatting, manage follow-up cron sweeps, and deploy to production.
- Agreed decisions to enforce:
  1. **Open Site Visit Prompt**: *"Aap kis date aur time par visit plan karna chahenge? 📅 (Jaise: 'Kal shaam 5:00 baje' ya 'Sunday 11:00 AM')"*.
  2. **Pre-visit Single Reminder**: 1-2 hours prior with Google Map Pin & executive contact. If user says "nahi aa paunga", immediately reschedule on the spot.
  3. **Post-visit Attendance Check**: 1-2 hours after visit: Option 1 (Visited) -> Price sheet / negotiation meeting; Option 2 (Not visited) -> Immediate reschedule.
  4. **Incomplete Lead Recovery**: Next day at 11:30 AM (recall pause point) -> Day 3 value teaser, max 2 nudges.
  5. **Drip Cadence**: Day 1 brochure/price breakdown -> Day 3 alternate properties -> Day 7 Friday Weekend VIP invite.
  6. **WABA Anti-Ban Safety**: Sweeps run strictly 11:00 AM - 6:30 PM IST, batch caps <= 20, 350-550ms jitter, instant DND opt-out.
  7. **Pagination ("Aur Dikhao")**: Show next 2 unseen properties; if exhausted, gracefully set team follow-up expectation.
  8. **Dialect Lock**: 100% mirroring for Gujlish, Hinglish, and English.
</context>
