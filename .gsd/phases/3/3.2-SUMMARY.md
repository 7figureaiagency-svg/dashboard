# Phase 3 Plan 2: Deterministic State Transition Routing & Elimination of Fragile Regex Cascades Summary

## Objective
Replace brittle cascading regular expressions and section-hijacking logic in `handleIncomingMessage()` with a deterministic Finite State Machine (FSM) router (`dispatchStateAction`). Route dialog transitions mathematically based on `(lead.state, validatedAction.intent)` to guarantee zero option hijacking, zero accidental criteria wipes, seamless returning-lead re-anchoring, and 100% Non-n8n architectural compliance.

## Changes Implemented

### 1. Deterministic FSM State Machine Router (`dispatchStateAction`)
- Defined dialog state types `DialogState`, context `DialogContext`, and transition output `DialogTransitionResult`.
- Implemented `dispatchStateAction(lead: any, actionResult: ClassifiedActionResult, context: DialogContext): Promise<DialogTransitionResult>` covering:
  - **Global Critical Interceptors**: `OPT_OUT` (sets `DROPPED`), `OFF_TOPIC` (preserves state, returns boundary reminder), `REQUEST_HUMAN_CALL` (dispatches high-priority sales alert), and `MARKET_ADVISORY`.
  - **Owner Intake Branching**: Routes in-progress owner states (`OWNER_CONFIG_PENDING` ... `OWNER_PHONE_PENDING`) directly into `handleOwnerFlow()`.
  - **Returning Owner Menu**: Allows selecting Option 1 (inquire) or Option 2 (list another property) with clean archival of previous drafts.
  - **Role Selection Pending**: Option 1 / Seeker intent transitions to `QUALIFYING`; Option 2 / Listing intent transitions to `OWNER_CONFIG_PENDING`.
  - **Options Sent (`OPTIONS_SENT` / `VISIT_REQUESTED`)**:
    - `SELECT_OPTION`: Maps selected option index to `selected_property_id` and prompts for visit slot ("Kal shaam 5 baje ya Sunday subah 11 baje"). Never hijacks lead search criteria.
    - `BOOK_VISIT`: Resolves property, validates slot hours (10 AM - 6 PM IST), inserts appointment into `site_visits`, dispatches sales alert, transitions to `SITE_VISIT_BOOKED`.
    - `CHANGE_REQUIREMENT`: Wipes stale criteria and transitions to `QUALIFYING`.
    - `ASK_FAQ` / `BROCHURE_REQUEST` / `MAP_REQUEST`: Returns property details and brochure without dropping out of `OPTIONS_SENT`.
  - **Criteria Confirmation Pending (`CRITERIA_CONFIRMATION_PENDING`)**:
    - Option 1 / Confirm True: Retains criteria, queries unseen inventory, transitions to `OPTIONS_SENT`.
    - Option 2 / Confirm False / Change: Wipes criteria cleanly, transitions to `QUALIFYING`.
  - **Site Visit Booked & Rescheduled (`SITE_VISIT_BOOKED` / `VISIT_RESCHEDULED`)**:
    - `GREETING`: Preserves booked visit and search criteria, outputs "Milte hain site par" with appointment time and property name.
    - `CANNOT_ATTEND_VISIT`: Updates `site_visits` status to `MISSED`, sets lead state to `VISIT_MISSED`, dispatches sales alert, and prompts reschedule with empathy.
    - `RESCHEDULE_VISIT`: Parses slot time, validates working hours, updates `site_visits` status to `RESCHEDULED`.
    - `CANCEL_VISIT`: Marks visit `CANCELLED`, dispatches sales alert.
  - **Post-Visit & Feedback (`SITE_VISIT_DONE`)**: Handles attendance confirmation and negotiation/loan intent.
  - **Sequential Qualification Cascade (`QUALIFYING`)**: Dispatches through `handleQualificationCascade()` to collect 5 qualification fields and query matching inventory.
